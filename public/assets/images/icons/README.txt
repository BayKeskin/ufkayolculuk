UFKA YOLCULUK - EKSİK SVG İKONLAR
==================================
Bu ek paket, ana tasarımda önceki pakette eksik kalan küçük ikonlar için hazırlandı.

Özellikle:
- Kayıt Bitiş Tarihi yanındaki sarı kullanıcı grubu ikonu
- Takım Lideri Portalı kullanıcı grubu
- Duyuru kartındaki 3 küçük ikon
- Giriş kullanıcı ikonu
- Küçük takvim ikonu
- Sıralama madalyaları
- Puan / XP / seviye / rozet ikonları
- Footer sosyal medya ikonları
- Oku & Dinle kulaklık ikonu
- Yetişkin kategorisi çanta ikonu
- Satır sağ ok ikonu

SVG'ler vektördür ve doğrudan frontend'de kullanılabilir.
