1. Kimlik Doğrulama & Proje Yetkilendirmesi

Zorunlu
Tüm API servisleri güvenlidir ve rest_users tablosunda tanımlı, bu projeye özel yetkilendirilmiş bir kullanıcı hesabı gerektirir. İstekler iki yöntemle doğrulanabilir:
🔑 Proje API Kimlik Doğrulama:
Bu servise erişmek için Ufka Yolculuk projesi için yetkilendirilmiş kullanıcı hesabınızı kullanınız.
🛡️ Proje İzolasyonu: Her kullanıcı yalnızca yetkilendirildiği projenin servislerine erişebilir.
📝 Tüm gelen REST istekleri (IP, kullanıcı adı, süre, parametreler ve yanıt gövdesi) otomatik olarak rest_logs tablosunda arşivlenir.
A) HTTP Basic Auth (Önerilen Yöntem) RFC 7617

İstek başlığında standart Authorization header gönderilir:

HTTP Header 
Authorization: Basic dXlfUmVzdC1Xb3JrZXI6VWZrQV9Zb2wtMTQ0OA==
B) Form Body ile Kimlik Doğrulama POST DATA

İstek gövdesine username ve password parametreleri eklenir:

cURL Örneği 
curl -X POST "https://ufkayolculuk.com/rest/get/getExams" \
  -d "username=uy_Rest-Worker" \
  -d "password=UfkA_Yol-1448"

2. Güvenlik, WAF ve Hız Sınırları

Güvenlik Duvarı
API uç noktaları DDoS, kaba kuvvet ve enjeksiyon saldırılarına karşı aktif WAF (Web Application Firewall) ile korunur.
Kural / Koruma Açıklama Engelleme Davranışı
Hız Sınırı (Rate Limit) Her istemci IP'si için dakikada maksimum 120 istek hakkı. HTTP 429 Too Many Requests (X-RateLimit başlıkları döner)
Brute-Force Koruması 10 dakika içinde 5 kez üst üste hatalı kimlik bilgisi gönderen IP'ler 15 dakika boyunca kilitlenir. HTTP 429 (Kalan saniye döner)
WAF Filtreleme SQL Injection, XSS, Path Traversal, Null-Byte ve şüpheli güvenlik tarayıcıları (sqlmap vb.) anında engellenir. HTTP 403 Forbidden
